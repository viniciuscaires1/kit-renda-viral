# Kit Renda Viral

Estúdio de vídeos animados em 3D com IA, do curso **Renda Viral**. Você não precisa entender o código: quem trabalha com ele é o Claude.

## Pelo celular (Módulo 8)
1. Toque no botão verde **Use this template** → **Create a new repository**.
2. Nome: `meu-estudio`. Marque **Private** e confirme.
3. No app do Claude, abra a opção **Code**, conecte o seu GitHub e escolha o repositório `meu-estudio`.
4. Cole o comando de preparação do Pacote de comandos (Bônus 2).

## No computador (Módulo 4)
Baixe o kit pelo material de apoio do curso (ou em **Code → Download ZIP**), descompacte dentro da pasta **Meu Estúdio** e siga as aulas 4.1 a 4.3.

## O que tem aqui dentro
- `CLAUDE.md`: o manual que o Claude lê para saber como o estúdio funciona.
- `modelos/`: as cenas dos vídeos de exemplo do curso (*Você construiu um piscinão* e *A mala no Uber*).
- `videos/`: cada vídeo ganha uma pasta aqui; o arquivo pronto é `final.mp4`.
- `teste/`: a cena do vídeo de teste de 10 segundos.

## Avisos
- A voz gratuita é ótima para aprender e testar. Antes de monetizar, use uma voz com licença comercial.
- Use só músicas com licença para uso comercial.
- Nas histórias de ficção, avise na legenda do post: “Ficção. Narração com voz gerada por IA.”
